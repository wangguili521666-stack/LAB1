
8.1 Database Schema
数据表	字段及类型
announcements	id BIGINT PK, title VARCHAR(200), content TEXT, type VARCHAR(30), publisher_id BIGINT FK, status VARCHAR(20), published_at DATETIME, expires_at DATETIME, created_at DATETIME, updated_at DATETIME
operation_logs	id BIGINT PK, user_id BIGINT NULL, module VARCHAR(20), action VARCHAR(100), target_type VARCHAR(50), target_id BIGINT NULL, request_method VARCHAR(10), request_path VARCHAR(255), result VARCHAR(20), ip_address VARCHAR(45), created_at DATETIME
公告状态：DRAFT / PUBLISHED / WITHDRAWN。
日志结果：SUCCESS / FAILURE。

8.3 API Contract
方法	路径	请求参数或 Body	返回 data
GET	/api/d3/announcements	type?, page?, page_size?	分页 Announcement
GET	/api/d3/announcements/{id}	id	Announcement
GET	/api/d3/admin/announcements	status?, type?, published_from?, published_to?, page?, page_size?	分页 Announcement
POST	/api/d3/announcements	title, content, type, expires_at?	Announcement
PATCH	/api/d3/announcements/{id}	title?, content?, type?, expires_at?	Announcement
POST	/api/d3/announcements/{id}/publish	无	Announcement
POST	/api/d3/announcements/{id}/withdraw	无	Announcement
POST	/api/d3/internal/logs	OperationLogCreate	{id}
GET	/api/d3/admin/logs	user_id?, module?, action?, result?, start_time?, end_time?, page?, page_size?	分页 OperationLog
公共公告接口只返回：
- status=PUBLISHED
- published_at 已到
- expires_at 为空或未过期
管理员接口可以查询草稿、已撤回与历史公告。
8.4 跨模块日志接口
POST /api/d3/internal/logs
{
  "user_id": "101",
  "module": "M1",
  "action": "BOOKING_CREATE",
  "target_type": "SEAT_BOOKING",
  "target_id": "501",
  "request_method": "POST",
  "request_path": "/api/m1/bookings",
  "result": "SUCCESS",
  "ip_address": "192.0.2.10"
}


返回：
{
  "code": "OK",
  "message": "success",
  "data": {
    "id": "1401"
  },
  "request_id": "req-007"
}


由 D3 服务端生成 created_at。
该接口只允许其他受信任的后端服务或统一网关调用，不能让浏览器用户自行提交任意日志。日志一经写入，不提供普通的修改和删除 API。
