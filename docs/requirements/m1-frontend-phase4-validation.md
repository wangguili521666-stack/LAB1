## 人工验收

1. 刷新 `http://127.0.0.1:5174/tests/m1-preview.html`，选择“系统管理员 · 管理与配置”并重置，在底部展开管理工作台。
2. 在预约管理里翻页，切换状态或教室编号（201、202），确认需要重新查询且结果更新。
3. 打开预约统计，检查所选日期、四个计数；切换顶部“统计字段缺失”“管理数据为空”验证未知与零的不同显示。
4. 打开配置，将预览里的 max_booking_hours 从 4 改为 6，确认仅此项更新；学生端仍为 4 小时，与本阶段约定一致。
5. 切换运营或自习室管理员，没有配置入口；切换学生，没有管理入口。切换拒绝访问场景，管理数据应清除。
6. 检查非法配置值、保存后刷新失败的反馈，缩窄窗口体验手机弹窗。
